# Jericho Personal Portfolio

A four-page HTML portfolio created for the Personal Portfolio Website Activity.

## Pages

- `index.html` - introduction and navigation
- `music.html` - five favorite songs with YouTube links
- `movies.html` - five favorite movies with trailer links
- `pictures.html` - five representative pictures with captions

## Run locally

Open `index.html` in a browser. The local SVG artwork in `assets/` is included so the visual design works without a build tool or server.

## Submission

Compress the complete `jericho-project` folder and rename the ZIP using the required format: `Surname_Section_Portfolio.zip`.
