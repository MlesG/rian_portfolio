# Maganito_3B_Portfolio

A four-page HTML portfolio for the Rian Personal Portfolio website, created for the Personal Portfolio Website Activity.

Project folder: `Maganito_3B_Portfolio`
Website: `Rian Personal Portfolio`

## Pages

- `index.html` - introduction and navigation for Rian Personal Portfolio
- `music.html` - five favorite songs with images and YouTube links
- `movies.html` - five favorite movies with poster images and YouTube trailer links
- `pictures.html` - ten representative pictures with captions

## Run the website

Extract the ZIP, open the `Maganito_3B_Portfolio` folder, and open `index.html` in a normal web browser. Use the navigation links to access the other pages. The website uses relative paths for local files and requires no Python server, build tool, backend, or database.

## Submission

Compress the complete `Maganito_3B_Portfolio` folder and rename the ZIP using the required format: `Surname_Section_Portfolio.zip`.
